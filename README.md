# 開店閉店レーダー

地域の開店、閉店、移転、休業、リニューアル情報をUGCで集め、LINEとXのアラート通知で届ける速報サービスです。

Canonical domain: https://kaitenheiten.com/

## Repository Name

open-close-radar

## Features

- 開店・閉店・移転・休業・リニューアル検索
- LINE地域アラートとX速報ポストの通知導線
- 店名、地域、駅、ジャンル、日付、確認状況、出典表示
- UGC投稿と確認待ちステータス
- SEO/AIO/LLMO向けFAQ、即答ブロック、構造化データ
- robots.txt / sitemap.xml / llms.txt
- 新店広告、通知スポンサー、求人、テナント、確認済み掲載、閉店前送客、代替店送客の収益導線
